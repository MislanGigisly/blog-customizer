# Blog Customizer

Учебный / шаблонный проект для кастомизации блога.  
Проект позволяет настраивать внешний вид статьи через панель управления: тема, шрифты, цвета и другие CSS-переменные.

## 🚀 <a id="install">Установка и запуск</a>

1. Клонировать репозиторий  
2. Установить зависимости `npm install`
3. Запустить проект `npm run start`

## :building_construction: <a id="structure">Структура проекта</a>

| Файл / папка        | Описание                                         |
| ------------------- | ------------------------------------------------ |
| `src/components/`   | UI-компоненты для панели настройки               |
| `src/styles/`       | SCSS / CSS стили, темы, переменные               |
| `src/utils/`        | Вспомогательные функции                          |
| `src/themes/`       | Файлы с темами (светлая / тёмная и др.)          |
| `src/index.js`      | Главная точка входа                              |
| `src/index.css`     | Глобальные стили                                 |
| `public/`           | Статические ресурсы (иконки, изображения и т.п.) |
| `.storybook/`       | Конфигурация Storybook (если используется)       |
| `package.json`      | Скрипты и зависимости проекта                    |
| `tsconfig.json`     | Настройки TypeScript (если используется)         |
| `.eslintrc.js`      | Конфигурация ESLint                              |
| `.stylelintrc.json` | Конфигурация Stylelint                           |
| `.prettierrc.js`    | Настройки Prettier                               |
| `README.md`         | Описание проекта                                 |

## 🎯 <a id="features">Особенности реализации</a>

- Панель настроек тем через CSS-переменные
- Возможность изменять цвета, шрифты, фон и др.
- Предварительный просмотр изменений в реальном времени
- Инструменты качества: линтер, форматирование кода
- Компонентный подход, переиспользуемость
